# `@erden/shacl-linux-x64-gnu`

Qualified `erden-shacl` executable (PurRDF `purrdf-shapes` 3.0.1, protocol `erden.shacl/v1`) for Linux x64 with glibc. This package is installed optionally by `@erden/shacl-distribution`; applications resolve it through that package so every integrity check runs before execution. The binary is the one the `shacl-build` workflow built twice, byte-identically, from the recorded source (`shacl/qualification/binary-reproducibility.json`).

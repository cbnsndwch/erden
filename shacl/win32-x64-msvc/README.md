# `@erden/shacl-win32-x64-msvc`

Qualified `erden-shacl` executable (PurRDF `purrdf-shapes` 3.0.1, protocol `erden.shacl/v1`) for Windows x64 (MSVC). This package is installed optionally by `@erden/shacl-distribution`; applications resolve it through that package so every integrity check runs before execution. The binary is the one the `shacl-build` workflow built twice, byte-identically, from the recorded source (`shacl/qualification/binary-reproducibility.json`).

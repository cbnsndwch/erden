# Security policy

Please report a suspected vulnerability privately, through GitHub's private vulnerability reporting: open the
repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue for it.

Say what you found, how to reproduce it, and which version or commit you used. We will acknowledge the report, keep
you informed while we look into it, and credit you in the fix unless you prefer otherwise.

Only the latest release receives security fixes.
